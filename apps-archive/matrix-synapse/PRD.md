# Product Requirements Document (PRD)

## Project: Matrix Synapse + PostgreSQL + Sliding Sync (Home Assistant Add-on)
- **Version:** `1.0.0-dev`
- **Author:** Matthijs van den Berg & Hermes Agent
- **Target Platform:** Home Assistant OS / Supervised (Docker Add-on)
- **Project Directory:** `/config/addons/matrix-synapse/`

---

## 1. Executive Summary
This Home Assistant Add-on provides a production-grade, state-of-the-art **Matrix Homeserver** stack running **Matrix Synapse**, an embedded **PostgreSQL** database engine, and the **Sliding Sync Proxy (MSC3575)**. It is tailored for high-performance Home Assistant environments with ample CPU and RAM, enabling instant multi-device chat, Element X client support, E2EE, and seamless integration with Home Assistant & Hermes Agent.

---

## 2. Core Functional Requirements

### 2.1 Matrix Synapse Homeserver
- **Engine:** Matrix Synapse (latest stable release).
- **Database:** Local embedded PostgreSQL 16+ instance persisted in `/data/postgres`.
- **Sliding Sync Proxy:** Embedded `sliding-sync` proxy for Element X client compatibility.
- **Federation:** Configurable Matrix federation on port 8448.
- **Registration:** Closed by default; admin registration tokens via config/UI.

### 2.2 Home Assistant System Mappings & Hardware Integration
- **Certificates Mapping (`ssl:rw`):** Direct read/write access to `/ssl` (e.g. `fullchain.pem` and `privkey.pem` generated by Let's Encrypt / Nginx Home Assistant SSL add-ons).
- **Config Mapping (`config:rw`):** Direct mapping to `/config` for storing shared secrets, bot tokens, and Home Assistant integration snippets.
- **Backup Target Mapping (`backup:rw`):** Dedicated backup target mapping to `/backup`. Integrates with Home Assistant Supervisor snapshot/backup routines via `pg_dumpall` database dumps and media archive export.
- **Data Persistence (`/data`):** Persistent storage across add-on updates for PostgreSQL data, Synapse media store, and signing keys.

### 2.3 Network & Port Exposure
- `8008`: Matrix Client HTTP API
- `8448`: Matrix Federation / Client HTTPS API
- `8009`: Sliding Sync Proxy HTTP
- `Ingress`: Home Assistant Supervisor Ingress integration for web admin and dashboard status.

---

## 3. Non-Functional & Security Requirements
1. **Security & PII Protection:**
   - No hardcoded secrets or default passwords in source code.
   - Credentials generated dynamically on first boot and stored in `/data/secrets.json`.
2. **Self-Healing & Diagnostics:**
   - Automated healthchecks for Synapse (`/_matrix/client/versions`), Postgres (`pg_isready`), and Sliding Sync.
   - Graceful shutdown handling (`SIGTERM`) ensuring clean Postgres WAL flushing.
3. **Developer Empowerment:**
   - One-click build and test workflow via `scripts/setup.sh` and `scripts/demo.sh`.
